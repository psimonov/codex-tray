# Codex Tray

[English](README.md) · Русский

---

Нативный индикатор оставшейся квоты Codex для системного трея Windows.

## Обзор

Codex Tray позволяет видеть текущую квоту Codex, не удерживая приложение или CLI на переднем плане. Программа работает как небольшой индикатор в системном трее Windows, использует авторизованную сессию Codex CLI текущего пользователя и показывает компактную информационную панель при наведении.

Приложение взаимодействует только с локально установленным `codex app-server`. Оно не запрашивает API-ключ и напрямую не читает и не копирует `~/.codex/auth.json`.

## Возможности

- Получение изменений квоты через серверные уведомления `account/rateLimits/updated`.
- Компактная DPI-aware панель со стабильными строками `Ключ: значение`.
- Поддержка светлой и тёмной темы, цвета акцента и прозрачности Windows.
- Привязанные к пиксельной сетке значки уровней квоты и состояний ошибок.
- Показ панели при наведении и скрытие после ухода курсора.
- Контекстное меню с управлением автозапуском Windows и явным закрытием приложения.
- Отсутствие системной всплывающей подсказки над значком.
- Отдельные состояния загрузки, переподключения, авторизации, подписки, отсутствующего CLI, исчерпанной квоты и ошибки app-server.

## Требования

- Windows 11 x86-64.
- [Codex CLI](https://learn.chatgpt.com/docs/codex/cli) в `PATH`.
- Авторизованная сессия Codex CLI, созданная командой `codex login`.

Сейчас в Codex Tray реализован только нативный Windows-backend. Артефакты для Linux, macOS и Windows ARM64 намеренно не публикуются до появления реализованных и протестированных платформенных backend-компонентов.

## Установка

1. Откройте [последний GitHub Release](https://github.com/psimonov/codex-tray/releases/latest).
2. Скачайте `codex-tray-<version>-windows-x86_64.exe` и соответствующий файл `.sha256`.
3. Проверьте контрольную сумму SHA-256.
4. Переместите исполняемый файл в любую постоянную папку и запустите его.

Пример проверки контрольной суммы в PowerShell:

```powershell
Get-FileHash .\codex-tray-0.2.0-windows-x86_64.exe -Algorithm SHA256
```

Установщик не требуется. Релиз состоит из одного переносимого исполняемого файла; команда `codex` остаётся внешним условием выполнения.

## Быстрый старт

```powershell
codex login
.\codex-tray-0.2.0-windows-x86_64.exe
```

Приложение запускается скрытым и добавляет значок в системный трей Windows.

## Использование

- Наведите курсор на значок, чтобы показать панель квоты.
- Уведите курсор со значка, чтобы скрыть панель.
- Нажмите правую кнопку мыши, чтобы скрыть панель и открыть контекстное меню.
- Переключите пункт **Запускать вместе с Windows**, чтобы зарегистрировать или удалить текущий путь исполняемого файла в пользовательском разделе Windows `Run`.
- Выберите **Закрыть**, чтобы остановить Codex Tray и дочерний процесс app-server.

Обновления квоты поступают через одно постоянное соединение с `codex app-server`. Codex Tray выполняет начальное чтение аккаунта и лимитов, объединяет последующие разреженные уведомления и переподключается после неожиданного завершения app-server.

## Конфигурация

У Codex Tray нет конфигурационного файла и переменных окружения. Необязательный автозапуск Windows управляется из контекстного меню и всегда использует динамически определённый путь запущенного исполняемого файла.

## Сборка из исходного кода

Репозиторий фиксирует требуемую версию Rust toolchain.

```powershell
git clone https://github.com/psimonov/codex-tray.git
Set-Location codex-tray
cargo build --release --locked
```

Результат сборки: `target\release\codex-tray.exe`.

## Тестирование

```powershell
cargo fmt --all -- --check

```

## Релизы

Версионные теги имеют формат `vMAJOR.MINOR.PATCH`. GitHub Actions проверяет соответствие тега версии в `Cargo.toml`, запускает проверки проекта, собирает Windows x86-64 executable и публикует исполняемый файл вместе с контрольной суммой SHA-256 в одном GitHub Release.

Сейчас проект поддерживает только Windows, поэтому публикуются исключительно артефакты Windows x86-64. Это явное платформенное решение, а не неподтверждённое заявление о кроссплатформенной поддержке.
