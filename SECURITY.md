# Security Policy

## Supported versions

Only the latest published release of Codex Tray receives security updates.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature on the repository **Security** tab. Include the affected version, reproduction steps, expected impact, and any suggested mitigation.

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or social media post. You should receive an initial response through GitHub within seven days.

Codex Tray uses the authenticated session managed by Codex CLI. Reports involving Codex authentication or the app-server protocol should clearly distinguish Codex Tray behavior from upstream Codex CLI behavior.
